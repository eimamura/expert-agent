# Domain Overview

This MVP models a subscription commerce domain. The agent answers questions about customers, orders, revenue, product adoption, and operational trends.

Common concepts:

- Active customer: a customer with at least one non-cancelled order in the analysis period.
- Monthly revenue: recognized order revenue grouped by calendar month.
- Churn risk: a signal that a customer has reduced recent order activity or has no recent activity.

Common questions include trend explanation, KPI definitions, table discovery, and data-quality caveats.
